# 📱 Pemrograman Mobile

Dokumentasi pembelajaran praktikum mata kuliah **Pemrograman Mobile**. Repository ini berisi modul praktikum, tugas, dan pengembangan aplikasi mobile berbasis React Native & Expo.

---

## 📁 Struktur Repository

```
Pemrograman-Mobile/
├── modul_0/   → Setup Dasar React Native & Expo
├── modul_1/   → Sintaks & UI Dasar
├── modul_2/   → State, Hooks, & Navigasi Page
├── modul_3/   → API Integration & Asynchronous Handling
├── modul_4/   → Local Storage & State Management
├── modul_5/   → Native Device Features (Camera, Location, Sensors)
├── modul_6/   → Testing, Build & Deployment (APK / Expo)
└── Tugas/     → Tugas Praktikum / Final Project
```
